# 🐍 Python Fundamentals & Algorithmic Scripts Archive

A consolidated collection of Python scripts, CLI games, and data analysis utilities developed during my introductory Computer Engineering coursework at **Ege University (2022–2023)**.

## 🎓 Academic Context
This monorepo archives early-stage coursework and independent coding exercises. It demonstrates baseline competency in procedural programming, algorithmic problem solving, file operations, and CLI-based UI flows prior to advanced studies in Computer Science at **HTW Dresden**.

## ⚙️ Tech Stack

* **Core Concepts:** Data Parsing, Flow Control, String Manipulation, Dynamic CLI Rendering, Basic Statistics
